## 1. Постановка проекта

**Запрос:** проанализировать контент Telegram-канала @krylikryli и определить,
что влияет на реакцию аудитории (реакции, комментарии, репосты), плюс
инженерный пайплайн.

**Ответ ассистента:** спроектирован пайплайн `raw → cleansed → dq → marts`,
структура каталогов, витрины `mart_*`, ноутбуки `01…04`, DAG Airflow,
тесты, README, `conclusions.md` и письмо.

**Итог:** выбран слойный подход (raw / cleansed / marts), ER = `(реакции +
комментарии + форварды) / просмотры`, из анализа исключены посты младше 7 дней
(`is_recent`).

## 3. Вопросы, найденные по ходу работы (и их решения)

### 3.1. Тавтология в «наивной» модели
- **Проблема:** `reactions`, `replies`, `forwards` входили и в целевую (ER),
  и в предикторы → ρ(replies, ER) = 0.708 возникало **по построению**.
- **Решение:** компоненты ER **исключены** из предикторов; оставлены
  структурные факторы (флаги, час, длина, интервал). R² финальной модели
  = 0.1769 (HC3, n = 1404).

### 3.2. Дубль витрины `mart_by_factor_vs_metric`
- **Проблема:** в `marts.sql` таблица создавалась дважды.
- **Решение:** оставить **один** согласованный блок; убрать промежуточные
  `mart_factor_*`; единый источник по часам — `mart_by_hour`.
- **⚠️ Важно:** все витрины `mart_*` собраны **в одном файле** `sql/marts.sql`.
  Отдельного файла `mart_factor_vs_metric.sql` **нет** — промежуточные
  `mart_factor_*` удалены как дубли.

### 3.3. Единый источник по часам
- **Проблема:** `mart_by_hour` и `mart_factor_hour` дублировали друг друга.
- **Решение:** оставлена `mart_by_hour`; фактор `hour` доступен внутри
  `mart_by_factor_vs_metric`.

### 3.4. `er` vs `mean_er` в ноутбуке `02`
- **Проблема:** ноутбук обращался к колонке `er`, которой нет в витринах.
- **Решение:** витрины отдают `mean_er` / `median_er`; `er` есть только в
  `cleansed_posts`. Запросы ячейки `02` приведены к `mean_er`.

### 3.5. Метрика «репостят vs обсуждают»
- **Имя:** `forward_to_comment_ratio` (ранее в черновиках фигурировала как
  `forwards_per_reply` — **старое имя, унифицировано**).
- **Решение:** метрику **оставляем** — она отвечает на вопрос
  «репостят vs обсуждают», считается **по группе** (сумма форвардов /
  сумма комментариев), т.к. на уровне отдельного поста при 0 комментариев
  отношение не определено.

### 3.6. Пропажа 31 строки в регрессии (n = 1404 vs 1435)
- **Причина:** NaN в `log_len` / `log_interval` (посты без текста /
  первый пост без интервала).
- **Решение:** зафиксировано одной строкой в выводах и README.

### 3.7. `skew / kurt`: −0.27 / 2.96
- **Проверка:** это остатки от `log(ER)`, а не от `ER` → значения корректны.
- **Решение:** в выводах отражено как «близко к норме по хвостам».

### 3.8. `is_pinned` (+0.78 при p = 0.51)
- **Проблема:** большой коэффициент, но незначим → читатель споткнётся.
- **Решение:** пояснить «широкий CI из-за малого n», вывод — «эффект не
  обнаружен», а не «эффекта нет».

### 3.9. Расхождение предпосылок (JB / BP / Levene / VIF)
- **Проблема:** в `conclusions.md` и шапке `03` фигурировали разные наборы
  и устаревшее «VIF < 1.5».
- **Решение:** список предпосылок выровнен; **VIF макс = 6.125** признан
  верным, фраза «VIF < 1.5» — ошибкой.

### 3.10. Расхождение имён графиков (`diag_qq_resid.png` vs `03_qq_resid.png`)
- **Проблема:** README и `conclusions` ссылаются на
  `figures/03_qq_resid.png`, `figures/03_resid_fitted.png`, а в `03` файлы
  сохранялись как `diag_*.png`.
- **Решение:** патчер `fix_03_notebook.py` (v2) приводит имена сохранения к
  каноническим (`03_qq_resid.png`, `03_resid_fitted.png`).

### 3.11. Итоговый аудит согласованности 4 документов
- **Проблема:** при финальной сверке `conclusions.md`, `README.md`,
  `letter_to_kryli.md` и `dialog.md` найдены редакционные нестыковки:
  (а) путь к письму указывался как `letter/letter_to_kryli.md`, а файл лежит
  в корне; (б) письмо не значилось в структуре README и «Артефактах сдачи»;
  (в) в dialog §5.3 не была отражена 4-я правка патчера (`hour_num → hour`);
  (г) фигурировало старое имя метрики `forwards_per_reply`;
  (д) в таблице «до/после» была спорная строка про медиану ER промо.
- **Решение:** путь к письму приведён к `letter_to_kryli.md`; письмо добавлено
  в структуру и артефакты README; в §5.3 добавлена 4-я правка; имя метрики
  унифицировано на `forward_to_comment_ratio`; строка про 0.0064 убрана
  (в предыдущей версии документов медиана промо не менялась — не оспаривалась).
- **Результат:** ключевые числа (F, p, H, коэффициенты, R², VIF, n, медианы)
  **сходятся** во всех четырёх файлах; остаточных числовых расхождений нет.
